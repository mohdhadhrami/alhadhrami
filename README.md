## 🎯 نظرة عامة

هذه اللعبة التفاعلية تساعد الطلاب على:
- فهم تركيب الجزيئات الكيميائية الأساسية
- التعرف على الذرات المختلفة وخصائصها
- تطوير مهارات التفكير المنطقي والعلمي
- التعلم من خلال التجربة والممارسة

## ✨ الميزات

### 1. واجهة مستخدم عربية كاملة
- تصميم عصري وجذاب
- دعم كامل للغة العربية
- واجهة سهلة الاستخدام

### 2. نظام السحب والإفلات
- سحب الذرات بسهولة إلى مساحة العمل
- تجربة تفاعلية سلسة
- إمكانية إزالة الذرات بالنقر عليها

### 3. مستويات تعليمية متدرجة
تحتوي اللعبة على 6 مستويات متدرجة الصعوبة:

#### المستوى 1: جزيئات بسيطة
- **الماء (H₂O)**: 100 نقطة
- **حمض الهيدروكلوريك (HCl)**: 100 نقطة
- **ثاني أكسيد الكربون (CO₂)**: 150 نقطة

#### المستوى 2: جزيئات متوسطة
- **الأمونيا (NH₃)**: 200 نقطة
- **بيروكسيد الهيدروجين (H₂O₂)**: 200 نقطة
- **الميثان (CH₄)**: 250 نقطة

### 4. نظام النقاط والتحفيز
- احصل على نقاط عند التركيب الصحيح
- نقاط مختلفة حسب صعوبة الجزيء
- متابعة تقدمك عبر المستويات

### 5. نظام التلميحات
- احصل على تلميحات مقابل 50 نقطة
- تلميحات مفيدة لكل جزيء
- ساعدك على التعلم بشكل أفضل

### 6. تغذية راجعة فورية
- تنبيهات عند الإجابة الصحيحة أو الخاطئة
- رسومات توضيحية للجزيئات
- شرح مفصل لكل جزيء

### 7. الذرات المتاحة
اللعبة تحتوي على الذرات التالية:
- **الهيدروجين (H)**: باللون الأزرق الفاتح
- **الأكسجين (O)**: باللون الأحمر
- **الكربون (C)**: باللون الأسود
- **النيتروجين (N)**: باللون الأزرق الداكن
- **الكلور (Cl)**: باللون الأخضر
- **الكبريت (S)**: باللون الأصفر

## 🎮 كيفية اللعب

1. **اقرأ التحدي**: انظر إلى اسم الجزيء المطلوب في القسم الأيمن
2. **اختر الذرات**: من القسم الأيمن، اختر الذرات المطلوبة
3. **اسحب وأفلت**: اسحب الذرات إلى مساحة العمل في الوسط
4. **رتب الذرات**: رتب الذرات لتشكيل الجزيء الصحيح
5. **فحص التركيب**: اضغط على زر "فحص التركيب" للتحقق
6. **احصل على النقاط**: إذا كان التركيب صحيحاً، ستحصل على النقاط
7. **انتقل للمستوى التالي**: أكمل جميع المستويات لتصبح خبيراً

## 📚 المستويات التعليمية

### المستوى 1: الأساسيات
تعلم تركيب الجزيئات البسيطة المكونة من 2-3 ذرات

### المستوى 2: التقدم
جزيئات أكثر تعقيداً مع 3-5 ذرات

### المستوى 3 وما بعده
يمكن إضافة المزيد من المستويات والجزيئات المعقدة

## 💻 التقنيات المستخدمة

- **HTML5**: هيكل الصفحة
- **CSS3**: التصميم والأنيميشن
- **JavaScript (Vanilla)**: المنطق والتفاعلية
- **Canvas API**: رسم الجزيئات
- **Drag and Drop API**: نظام السحب والإفلات

## 🚀 كيفية التشغيل

### الطريقة 1: فتح مباشر
1. قم بتحميل الملفات الثلاثة:
   - `index.html`
   - `style.css`
   - `script.js`
2. افتح ملف `index.html` في أي متصفح حديث

### الطريقة 2: استخدام خادم محلي
```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx http-server
```

ثم افتح المتصفح على `http://localhost:8000`

## 🎓 الأهداف التعليمية

هذه اللعبة تساعد الطلاب على:

1. **فهم تركيب الجزيئات**: معرفة كيفية ارتباط الذرات لتشكيل جزيئات
2. **التعرف على الصيغ الكيميائية**: قراءة وفهم الصيغ مثل H₂O، CO₂
3. **تطوير المهارات المنطقية**: التفكير في كيفية تركيب الجزيئات
4. **التعلم التفاعلي**: التعلم من خلال التجربة والخطأ
5. **الاستمتاع بالعلوم**: جعل الكيمياء ممتعة وجذابة

## 🎨 التخصيص

يمكنك بسهولة إضافة المزيد من:

### إضافة جزيئات جديدة
قم بتعديل مصفوفة `molecules` في ملف `script.js`:

```javascript
{
    id: 7,
    name: 'اسم الجزيء',
    formula: 'الصيغة',
    description: 'الوصف',
    atoms: { H: 2, O: 1 }, // عدد كل ذرة
    difficulty: 1,
    points: 100,
    hint: 'التلميح',
    structure: [
        { type: 'O', x: 100, y: 100 },
        { type: 'H', x: 50, y: 140 }
    ]
}
```

### إضافة ذرات جديدة
قم بتعديل كائن `atomTypes` في ملف `script.js`:

```javascript
atomTypes = {
    // ... الذرات الموجودة
    Ca: {
        name: 'كالسيوم',
        symbol: 'Ca',
        class: 'calcium',
        color: '#9e9e9e'
    }
}
```

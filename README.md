# صفحة تعليمية تفاعلية: القطبية الجزيئية

صفحة ويب تعليمية تفاعلية (RTL بالعربية) لدرس **القطبية الجزيئية وتأثيرها على الخواص الفيزيائية** للصف الحادي عشر.

## المحتويات
- `index.html`: الهيكل العام والتدفق التعليمي.
- `styles.css`: التصميم والاستجابة.
- `app.js`: المنطق التفاعلي، عارض الجزيئات 3D، وحفظ البيانات محليًا.

## التشغيل محليًا
يمكن تشغيل الصفحة مباشرة بفتح `index.html` في المتصفح، أو باستخدام خادم محلي:

```bash
python -m http.server 8000
```
ثم افتح: `http://localhost:8000`

## النشر على GitHub Pages
1. ارفع الملفات إلى الفرع الرئيسي (مثل `main`).
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر المصدر: `main` ثم `/root`.
4. احفظ التغييرات، وستظهر الصفحة على رابط GitHub Pages.

## ملاحظات تقنية
- يستخدم العارض ثلاثي الأبعاد مكتبة [3Dmol.js](https://3dmol.csb.pitt.edu/).
- يتم حفظ بيانات ورقة العمل محليًا باستخدام `localStorage`.
- يمكن للطلاب تنزيل لقطة PNG من العارض عبر زر "التقاط لقطة".
